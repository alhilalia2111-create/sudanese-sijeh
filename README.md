# السيجة السودانية

إصدار متصفح مستقل ومتجاوب للعبة السيجة، مناسب للهاتف والكمبيوتر.

## التشغيل

- افتح `index.html` في متصفح حديث. لا يحتاج إلى Python أو تثبيت أو اتصال بالإنترنت.
- على الهاتف، افتح الملف بمتصفح يدعم صفحات HTML المحلية. إذا كان الهاتف لا يشغّل الملفات المحلية من مدير الملفات، ارفع `index.html` كما هو إلى استضافة صفحات ثابتة وافتح الرابط.
- للنشر على الإنترنت، ارفع الملف وحده إلى GitHub Pages أو Netlify أو أي استضافة ثابتة؛ لا توجد عملية بناء أو مكتبات خارجية.

## طريقة اللعب

- لاعبان على الجهاز نفسه؛ الفريق النيلي يبدأ.
- لكل فريق 12 حجراً، ويوضع حجران بالتناوب في كل دور على رقعة 7×7.
- بعد التوزيع، تتحرك الأحجار خانة واحدة أفقياً أو رأسياً، ويظل الميدان الوسطي محجوزاً.
- أسر حجر الخصم يكون بإحاطته بين حجرين من فريقك على خط مستقيم.
- الفوز بأسر كل أحجار الخصم أو منعه من أي حركة قانونية.
- زر «تراجع» يعيد آخر فعل، بما في ذلك وضع الأحجار.

اللعبة ملف HTML واحد، وجميع التنسيقات والمنطق مضمنة فيه؛ لا تستخدم موارد خارجية.
